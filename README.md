# TP3 Portfolio / Achilli Brisa #
Repositorio correspondiente al Trabajo Práctico 3 que fue la realización de nuestro portfolio para de la materia de Computación 3 de la carrera de Diseño y Comunicación Visual en la **UNLa** (Universidad Nacional de Lanús).

## Se utilizaron las siguientes herramientas ##
- HTML5
- CSS
- Flex Box

  
## Especificaciones Técnicas ##
- Se utilizó Visual Studio Code para el diseño y maquetación de la pagina web.
- El tamaño de pantalla donde se realizó este trabajo es de 1920x1080px.
