# TP1 Curriculum Vitae / Achilli Brisa #
Este trabajo fue mi primer acercamiento al desarrollo web en el marco de la materia Computación III en la UNLa. Este repositorio reúne el proceso y la versión final de la maquetación de mi currículum vitae, estructurado con código en HTML5 y CSS. Como metodología de trabajo, se aplicaron primero las etiquetas básicas y luego se fue construyendo la página dandole situaciones más complejas.

## Se utilizaron las siguientes herramientas ##
- HTML5
- CSS
- Flex Box
- Box Model
  
## Especificaciones Técnicas ##
- Se utilizó Visual Studio Code para el diseño y maquetación de la pagina web.
- El tamaño de pantalla donde se realizó este trabajo es de 1920x1080px.
